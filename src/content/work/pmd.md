Piano Music Database (PMD) is a free online tool that helps you easily & quickly find music for your piano students. Search for pieces that incorporate specific pedagogical concepts; filter your results by mood, theme, style, and more!

Initial versions of the website were made using <a href="https://WordPress.org" title="Visit WordPress at WordPress.org" target="_blank" rel="noopener noreferrer">WordPress</a> to test the feasibility of a piano music database website on mobile and desktop. Currently the website is a "<a href="https://nextjs.org" title="Visit Next.js at NextJS.org" target="_blank" rel="noopener noreferrer">Next.js</a> with <a href="https://tailwindcss.com" title="Visit Tailwind CSS at TailwindCSS.com" target="_blank" rel="noopener noreferrer">Tailwind CSS</a>" PWA/website which is deployed from a <a href="https://github.com" title="Visit GitHub at github.com" target="_blank" rel="noopener noreferrer">GitHub</a> repository using <a href="https://netlify.com" title="Visit Netlify at netlify.com" target="_blank" rel="noopener noreferrer">Netlify</a>. The search engine is powered by <a href="https://typesense.org" title="Visit Typesense at Typesense.org" target="_blank" rel="noopener noreferrer">Typesense</a> and the work data is gathered from a <a href="https://strapi.io" title="Visit Strapi at Strapi.io" target="_blank" rel="noopener noreferrer">Strapi</a> API.

The current branding (logo, font, color, social media post/email newsletter images, banners, etc) is designed using Adobe Illustrator and Adobe Photoshop.
